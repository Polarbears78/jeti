# 외부(인터넷) 접속 설정 — Cloudflare Tunnel

## 이미 완료된 것

**접속 암호 기능을 챗봇에 추가하고 젯슨에 배포했습니다.** 인터넷에 공개해도
아무나 들어올 수 없습니다. 아래 항목을 실제로 시험해서 확인했습니다.

- 암호 없이 학생 페이지 접속 → 로그인 화면만 표시 (챗봇 안 보임)
- 암호 없이 챗봇 API 직접 호출 → 401 차단
- 틀린 암호 → 거부
- 학생 암호로 교사 페이지 접근 → 차단 (교사 비밀키 별도 필요)
- 교사 비밀키가 더 이상 주소창에 노출되지 않음 (로그인 방식으로 변경)
- 한 사람이 10분에 20개 넘게 질문하면 자동 차단 (남용 방지)

| 구분 | 암호 |
|---|---|
| 학생 접속 암호 | `<학생 접속 암호>` |
| 교사 비밀키 | `<교사 비밀키>` |

실제 암호는 `보안정보.txt` 에 적어 뒀습니다 (GitHub에 올라가지 않는 파일).
암호를 바꾸려면 젯슨의 `~/chatbot/config.json` 을 수정하고
`sudo systemctl restart chatbot` 하세요.

## 남은 작업 — 아래 명령을 직접 실행해 주세요

Cloudflare 프로그램 설치는 제 보안 정책상 대신 해드릴 수 없어서
(인터넷에서 받은 프로그램을 원격 기기에 설치하는 동작) 직접 실행이 필요합니다.

### 1단계: cloudflared 설치

PowerShell에서 아래를 실행하세요. 중간에 젯슨 비밀번호(`<젯슨 비밀번호>`)를 물어봅니다.

```bash
ssh ymk@<젯슨 IP> "cd /tmp && curl -fsSL -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb && sudo dpkg -i cloudflared.deb && cloudflared --version"
```

마지막에 `cloudflared version 20xx.x.x` 가 나오면 성공입니다.

### 2단계: 터널 실행 및 주소 확인

```bash
ssh ymk@<젯슨 IP> "nohup cloudflared tunnel --no-autoupdate --url http://127.0.0.1:8000 > ~/chatbot/tunnel.log 2>&1 & sleep 25; grep -oE 'https://[a-z0-9-]+\.trycloudflare\.com' ~/chatbot/tunnel.log | tail -1"
```

출력되는 `https://○○○-○○○-○○○.trycloudflare.com` 이 **외부 접속 주소**입니다.
학생은 이 주소로 들어가 접속 암호를 입력하면 됩니다.

### 3단계(선택): 부팅 시 자동 실행

터널을 항상 켜두시려면:

```bash
ssh ymk@<젯슨 IP> "printf '[Unit]\nDescription=Cloudflare Tunnel\nAfter=network-online.target chatbot.service\n\n[Service]\nUser=ymk\nExecStart=/usr/local/bin/cloudflared tunnel --no-autoupdate --url http://127.0.0.1:8000 --logfile /home/ymk/chatbot/tunnel.log\nRestart=always\nRestartSec=10\n\n[Install]\nWantedBy=multi-user.target\n' | sudo tee /etc/systemd/system/cftunnel.service && sudo systemctl daemon-reload && sudo systemctl enable --now cftunnel"
```

이후 주소를 확인하려면:

```bash
ssh ymk@<젯슨 IP> "grep -oE 'https://[a-z0-9-]+\.trycloudflare\.com' ~/chatbot/tunnel.log | tail -1"
```

## 꼭 알아두실 점

**주소가 재시작할 때마다 바뀝니다.** 무료 임시 터널(trycloudflare)의 특성입니다.
젯슨을 껐다 켜거나 터널이 재시작되면 새 주소가 발급되므로, 수업 전에 위 명령으로
주소를 확인해서 학생들에게 알려주셔야 합니다.

**고정 주소를 원하시면** Cloudflare 무료 계정과 도메인(연 1~2만원)이 필요합니다.
`chatbot.학교도메인.com` 같은 주소를 영구적으로 쓸 수 있습니다. 필요하시면
도메인 준비 후 말씀해 주세요.

**성능 한계.** 젯슨은 질문 하나를 약 11초에 걸쳐 순서대로 처리합니다. 30명이
저녁에 동시에 접속하면 뒷사람은 몇 분씩 기다립니다. 집에서 쓰는 용도라면
"각자 다른 시간에" 안내하시거나, 학급별로 시간을 나누는 편이 좋습니다.

**전기·발열.** 24시간 켜두면 월 2~3천원 수준의 전기료가 듭니다. 발열이 있으니
통풍이 되는 곳에 두세요.

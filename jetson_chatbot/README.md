# 수업용 LLM 챗봇 (Jetson Orin Nano)

학생이 브라우저로 질문하면 AI가 답하고, 교사가 질문 기록을 모아 볼 수 있는
수업 보조 도구입니다. 인터넷 연결 없이 **젯슨 보드 안에서만** 동작하므로
학생 질문이 외부로 나가지 않습니다.

## 기능

- **학생용 채팅 페이지** — 접속 암호를 입력해야 들어갈 수 있고, 답변이 실시간으로 표시됨
- **자동 기록** — 모든 질문·답변이 학생 이름·시각과 함께 저장됨
- **교사용 페이지** — 날짜별 질문 열람, CSV 내려받기, 그리고 그날 질문을
  주제별로 분류하고 보충 수업까지 제안해 주는 **AI 요약** 기능
- **남용 방지** — 한 사람이 10분에 20개를 넘겨 질문하면 자동 차단

## 필요한 것

- Jetson Orin Nano (8GB) + JetPack 6.x
- [Ollama](https://ollama.com) 와 한국어 모델
- Python 3, Flask, requests

## 설치

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull exaone3.5:7.8b
pip3 install flask requests

git clone <이 저장소 주소> chatbot && cd chatbot
cp config.example.json config.json   # 암호를 알맞게 수정
python3 app.py
```

브라우저에서 `http://<젯슨IP>:8000` 으로 접속합니다.
자동 시작 등록과 운영 방법은 [설치방법.md](설치방법.md),
외부 접속은 [외부접속_설정.md](외부접속_설정.md)를 참고하세요.

## 모델 선택

젯슨 오린 나노(GPU 메모리 6.4GB)에서 같은 질문으로 실측한 결과입니다.

| 모델 | 응답 시간 | 평가 |
|---|---|---|
| **exaone3.5:7.8b** | 11.0초 | **채택.** 한국어가 자연스럽고 사실 오류 없음 |
| gemma3:4b | 8.8초 | 가장 빠르지만 없는 사실을 지어내는 경우 있음 |
| gemma4:e2b-it-qat | 20.0초 | 내부 추론에 토큰을 많이 써서 체감이 가장 느림 |
| qwen2.5:7b | — | 답변 중간에 중국어가 섞여 부적합 |

초당 토큰 수가 빠르다고 체감이 빠른 것은 아닙니다. gemma4는 27토큰/초로 가장
빨랐지만 답변 하나에 토큰을 577개나 써서 결과적으로 가장 오래 걸렸습니다.

## 주의

- **AI 답변은 틀릴 수 있습니다.** 검증 중 "DS18B20 센서는 열전대 원리"라는
  오답이 나왔습니다(실제로는 반도체 방식). 학생들에게 확인하고 쓰도록 안내하세요.
- **질문은 순서대로 처리됩니다.** 여러 명이 동시에 물으면 뒷사람은 기다립니다.
  조별로 대표 1명이 질문하는 방식을 권합니다.
- `config.json` 에는 암호가 들어가므로 **저장소에 올리지 마세요**
  (`.gitignore`에 등록되어 있습니다).

## 학생 안내문 (그대로 사용 가능)

1. 학교 와이파이에 연결하세요 (모바일 데이터 끄기).
2. 브라우저 주소창에 **http://<젯슨 IP>:8000** 을 입력하세요.
3. 맨 위에 **이름과 조**를 적으세요 (예: `2조 김철수`). 적어야 누구 질문인지 기록됩니다.
4. 궁금한 것을 입력하고 전송하세요. 답변이 나오기까지 10초쯤 걸립니다.

## 알아두실 점

- **동시 질문은 순서대로 처리됩니다.** 5개 조가 한꺼번에 물으면 마지막 조는 1분쯤 기다립니다.
  조별로 대표 1명이 질문하게 하면 원활합니다.
- **AI 답변은 틀릴 수 있습니다.** 검증 중 "DS18B20 센서는 열전대 원리"라는 오답이 나왔습니다
  (실제로는 반도체 방식). 특히 특정 부품·제품의 기술적 세부사항은 부정확할 수 있으니,
  학생들에게 "AI 답을 그대로 믿지 말고 확인하라"고 안내해 주세요.
- **질문 기록은 젯슨 안에만 저장됩니다** (`~/chatbot/chatlog.db`). 외부로 나가지 않습니다.
  백업하려면 이 파일 하나만 복사하면 됩니다.

## 문제가 생겼을 때

**학생이 접속을 못 할 때** — 젯슨 IP가 바뀌었을 수 있습니다. 젯슨에서 확인:

```bash
ssh ymk@<젯슨 IP> "hostname -I"
```

접속 자체가 안 되면 공유기 관리 페이지에서 `jetson` 이라는 이름의 기기를 찾으세요.
IP가 자주 바뀌면 공유기에서 **고정 IP 할당**을 설정하시는 걸 권합니다.

**챗봇이 응답하지 않을 때**

```bash
ssh ymk@<젯슨 IP> "sudo systemctl restart chatbot ollama"
```

**상태 확인**

```bash
ssh ymk@<젯슨 IP> "systemctl is-active chatbot ollama; ollama list"
```

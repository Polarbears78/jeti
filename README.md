# 중학교 과학 가상 실험 (Science Virtual Lab)

모바일 기기에 최적화된 중학교 과학 인터랙티브 시뮬레이션 모음입니다.
상위 페이지(`index.html`)에서 아이콘을 눌러 각 실험으로 이동합니다.

- **실험 목록(상위 페이지)** (`index.html`): 아이콘 카드로 각 실험에 진입
- **보일 법칙** (`boyle.html`): 온도 일정 → 압력과 부피의 반비례 관계
- **샤를 법칙** (`charles.html`): 압력 일정 → 온도와 부피의 정비례 관계
- **아보가드로 법칙** (`avogadro.html`): 온도·압력 일정 → 입자 수와 부피의 정비례 관계
- **이온의 이동** (`ion.html`): 전류를 흘려 줄 때 수용액 속 이온이 전극으로 이동
- **소리 오실로스코프** (`wave.html`): 소리의 세기·높이를 바꿔 파형을 분석
- **옴의 법칙** (`ohm.html`): 회로에서 전압과 전류의 관계를 그래프로 분석
- **전류와 저항** (`resistance.html`): 전압 일정 → 전류와 저항의 반비례 관계
- **AR 가속도 측정** (`accel.html`): 카메라 화면 위에서 가속도 센서로 측정(AR)
- **Pico 온도 측정** (`pico/`): Pico 2 W + 방수 온도센서(DS18B20)를 웹서버로 띄워 실제 온도를 기록·CSV 저장 (실물 하드웨어)

각 실험 페이지 상단의 **‘← 실험 목록’** 버튼으로 상위 페이지로 돌아갈 수 있습니다.
실험 페이지끼리 직접 이동하는 메뉴는 없습니다.

# 보일 법칙 (Boyle's Law)

## 개요

온도가 일정할 때 기체의 **압력(P)** 과 **부피(V)** 가 반비례한다는
보일 법칙(P₁V₁ = P₂V₂)을 손으로 직접 조작하며 관찰할 수 있습니다.

## 기능

- **피스톤 드래그**: 실린더의 피스톤을 위아래로 끌어 부피를 조절 (터치/마우스)
- **슬라이더 조작**: 손가락으로 부피를 정밀하게 조절
- **실시간 측정값**: 부피 V, 압력 P, 그리고 일정하게 유지되는 P×V 값 표시
- **압력 게이지**: 부피 변화에 따라 바늘이 실시간으로 움직임
- **기체 입자 운동 애니메이션**: 입자가 실제로 직선 운동하다 벽에 충돌·반사
- **벽 충돌 시각화**: 입자가 벽에 부딪히는 순간 섬광 효과 표시, 부피가 줄면 충돌이 잦아짐
- **충돌 빈도 측정**: 지난 1초간 벽 충돌 횟수(회/초)를 막대와 숫자로 표시 (압력과 비례)
- 온도가 일정하므로 입자의 **속력은 일정**하게 유지(등온) — 충돌 *빈도*만 변함
- **P–V 그래프**: 반비례 곡선 위에 현재 측정점을 실시간 표시
- **초기화 버튼**: 기본 상태(V=5L, P=1atm)로 복원

## 사용 방법

`index.html`(실험 목록)을 모바일 브라우저(또는 PC 브라우저)에서 열면 됩니다.
별도의 빌드나 서버가 필요 없는 순수 HTML/CSS/JavaScript 구성입니다.

```
index.html   # 상위 페이지(실험 목록, 아이콘 카드)
home.css     # 상위 페이지 스타일
boyle.html   # 보일 법칙 페이지 구조
style.css    # 보일 법칙 모바일 반응형 스타일
script.js    # 보일 법칙 물리 계산 · 입자/그래프 시뮬레이션
```

## 물리 모델

- PV = K (상수), 기준점 V=5L → P=1atm 이므로 K=5
- 온도 300K로 고정 (등온 과정)
- 부피 범위: 1 L ~ 10 L

# 샤를 법칙 (Charles's Law)

## 개요

압력이 일정할 때 기체의 **부피(V)** 가 **절대온도(T, K)** 에 정비례한다는
샤를 법칙(V₁/T₁ = V₂/T₂)을, 온도와 입자 운동의 관계로 관찰할 수 있습니다.

## 기능

- **온도 슬라이더**: 가열/냉각으로 온도(100~600K) 조절 — 불꽃과 온도계가 함께 반응
- **입자 속력 ↑**: 온도가 오르면 입자가 더 빠르게 운동 (속력 막대로 표시)
- **부피 ∝ T**: 빨라진 입자가 피스톤을 밀어 올려 부피가 커짐 (압력은 일정)
- **온도별 입자 색**: 차가울 때 하늘색 → 뜨거울 때 빨강으로 변화
- **실시간 측정값**: 온도 T, 부피 V, 그리고 일정하게 유지되는 V÷T 값
- **V–T 그래프**: 원점을 지나는 정비례 직선 위에 현재 측정점 표시
- **초기화 버튼**: 기본 상태(T=300K, V=5L)로 복원

## 물리 모델

- V / T = 상수 (압력 일정), 기준점 T=300K → V=5L 이므로 상수 = 1/60
- 입자 속력은 온도가 높을수록 빠르게 (시각화는 상댓값으로 온도에 비례 표시)
- 온도 범위: 100 K ~ 600 K, 부피 범위: 약 1.7 L ~ 10 L

## 파일

```
charles.html  # 샤를 법칙 페이지 구조
charles.css   # 스타일 (따뜻한 테마 + 불꽃)
charles.js    # 물리 계산 · 입자/그래프 시뮬레이션
```

# 아보가드로 법칙 (Avogadro's Law)

## 개요

온도와 압력이 일정할 때 기체의 **부피(V)** 가 기체 **입자 수(N, 몰 수)** 에
정비례한다는 아보가드로 법칙(V₁/N₁ = V₂/N₂)을 관찰할 수 있습니다.

## 기능

- **주입 / 배출 버튼·슬라이더**: 기체 양(1~10 mol)을 늘리거나 줄임
- **입자 수 변화**: 기체를 넣으면 화면의 입자 개수가 실제로 늘어남
- **부피 ∝ N**: 입자가 많아진 만큼 피스톤이 올라가 부피가 비례해 커짐
- **밀도·속력 일정**: 입자 수와 부피가 함께 늘어 밀도가 유지되므로 압력·온도 일정
- **실시간 측정값**: 입자 수 N, 부피 V, 그리고 일정하게 유지되는 V÷N 값
- **V–N 그래프**: 원점을 지나는 정비례 직선 위에 현재 측정점 표시
- **초기화 버튼**: 기본 상태(N=5mol, V=5L)로 복원

## 물리 모델

- V / N = 상수 (온도·압력 일정), 기준점 N=5mol → V=5L 이므로 상수 = 1
- 입자 속력 일정(온도 일정), 단위 부피당 입자 수(밀도) 일정 → 압력 일정
- 기체 양 범위: 1 mol ~ 10 mol, 부피 범위: 1 L ~ 10 L

## 파일

```
avogadro.html  # 아보가드로 법칙 페이지 구조
avogadro.css   # 스타일 (초록 테마)
avogadro.js    # 물리 계산 · 입자/그래프 시뮬레이션
```

# 이온의 이동 (Ion Migration / 전기 분해)

## 개요

전해질 수용액에 전류를 흘려 줄 때, 수용액 속의 **양이온(+)** 과 **음이온(−)** 이
서로 반대 전하의 전극으로 이동하는 모습을 관찰할 수 있습니다.

## 기능

- **전류 ON/OFF 스위치**: 전류를 흘리면 이온이 전극을 향해 일제히 이동
- **전압(전류 세기) 슬라이더**: 전압을 높이면 이온이 더 빠르게 끌려가 전극에 더 자주 도달
- **양이온(+) → 음극(−)**: 빨간 이온이 왼쪽 음극으로 이동
- **음이온(−) → 양극(+)**: 파란 이온이 오른쪽 양극으로 이동
- **무질서한 열운동**: 전류가 없을 때는 이온이 사방으로 무질서하게 떠다님
- **전극 도달 효과**: 이온이 전극에 닿는 순간 섬광이 일고 도달 수가 누적됨
- **실시간 측정값**: 전압 V, 전류 I, 전극 도달 이온 수
- **초기화 버튼**: 전류 OFF·기본 전압(3 V) 상태로 복원

## 모형 설명

- 전해질이 물에 녹으면 양이온·음이온으로 나뉘어 자유롭게 이동
- 전류를 흘리면 전기장에 의해 양이온은 음극으로, 음이온은 양극으로 끌려감
- 전압이 높을수록 이온이 끌리는 속도(드리프트)와 전류 세기가 커짐 (모형용 환산: I ≈ 40·V mA)
- 전극에 도달한 이온은 가운데 부근에서 다시 등장해 전류가 계속 흐르는 모습을 표현

## 파일

```
ion.html  # 이온의 이동 페이지 구조
ion.css   # 스타일 (전기 보라/청록 테마)
ion.js    # 이온 운동·전극 이동 시뮬레이션
```

# 소리 오실로스코프 (Sound Oscilloscope)

## 개요

소리의 **세기(진폭)** 와 **높이(진동수)** 를 조절하며 오실로스코프 화면의
**파형**이 어떻게 달라지는지 관찰하고, 실제 소리도 함께 들을 수 있습니다.

## 기능

- **세기(진폭) 슬라이더**: 올리면 파형이 위아래로 커지고 소리가 커짐
- **높이(진동수) 슬라이더**: 올리면 화면의 물결이 촘촘해지고(진동수↑) 소리가 높아짐
- **소리 듣기 버튼**: Web Audio API로 실제 사인파 톤을 재생(세기·높이 실시간 반영)
- **실시간 측정값**: 세기(%), 진동수(Hz), 주기 T(ms), 파장 λ(m)
- **형광 그린 트레이스**: 잔광(글로우)과 격자가 있는 오실로스코프 화면 연출
- **초기화 버튼**: 기본 상태(세기 60%, 300Hz)로 복원

## 모형 설명

- 소리의 세기 ∝ 진폭, 소리의 높이 ∝ 진동수
- 화면에 보이는 파동 수 = 진동수 / 100 (진동수가 클수록 파장이 짧아짐)
- 주기 T = 1 ÷ f, 파장 λ = v ÷ f (소리의 속력 v = 340 m/s 기준)
- 청력 보호를 위해 재생 음량(gain)은 최대 0.18로 제한

## 파일

```
wave.html  # 소리 오실로스코프 페이지 구조
wave.css   # 스타일 (오실로스코프 그린 테마)
wave.js    # 파형 그리기 · Web Audio 소리 재생
```

# 옴의 법칙 (Ohm's Law)

## 개요

전지·저항·전류계·전압계로 이루어진 **회로**에서 **전압(V)** 과 **전류(I)** 의
관계를 직접 조절하며 관찰하고, **전압–전류 그래프**로 분석합니다.

## 기능

- **전압 슬라이더**: 전지 전압(0~10V)을 올리면 전류가 비례해 커짐
- **저항 슬라이더**: 저항(2~10Ω)을 키우면 같은 전압에서 전류가 줄고 그래프 기울기(1/R)가 완만해짐
- **회로도 + 전류 애니메이션**: 도선을 따라 전자가 흐르며, 전류가 클수록 빠르게 이동
- **전류계(A)·전압계(V)**: 직렬·병렬로 연결된 계기 표시
- **실시간 측정값**: 전압 V, 저항 R, 전류 I(=V÷R)
- **V–I 그래프**: 원점을 지나는 정비례 직선 + 전압을 바꿀 때마다 찍히는 측정점
- **초기화 버튼**: 기본 상태(4V, 4Ω)로 복원

## 모형 설명

- 옴의 법칙 V = I × R, 즉 I = V ÷ R (저항 일정 시 전류 ∝ 전압)
- 그래프 기울기 = 1 / R (저항이 클수록 완만)
- 전압 범위 0~10 V, 저항 범위 2~10 Ω, 전류축 최대 5 A

## 파일

```
ohm.html  # 옴의 법칙 페이지 구조(회로 SVG 포함)
ohm.css   # 스타일 (회로/그래프 테마)
ohm.js    # 전류 애니메이션 · V-I 그래프 계산
```

# 전류와 저항 (Current & Resistance)

## 개요

**전압을 일정하게** 유지한 채 **저항(R)** 을 바꾸며 **전류(I)** 가 어떻게
변하는지 관찰하고, **저항–전류 그래프**(반비례 곡선)로 분석합니다.

## 기능

- **저항 슬라이더**: 저항(1~10Ω)을 키우면 전류가 반비례로 줄고, 저항의 지그재그 굴곡이 많아짐
- **전압 슬라이더**: 일정하게 유지할 전압(2~10V)을 바꾸면 반비례 곡선 전체가 이동
- **회로도 + 전류 애니메이션**: 전류가 줄면 전자가 더 천천히 흐름
- **실시간 측정값**: 전압 V(일정), 저항 R, 전류 I(=V÷R)
- **R–I 그래프**: 반비례 곡선 + 저항을 바꿀 때마다 찍히는 측정점
- **초기화 버튼**: 기본 상태(6V, 4Ω)로 복원

## 모형 설명

- 전압 일정 시 I = V ÷ R, 즉 전류는 저항에 반비례 (I ∝ 1/R)
- 저항이 2배가 되면 전류는 절반으로 감소
- 저항 범위 1~10 Ω, 전압 범위 2~10 V, 전류축 최대 10 A

## 파일

```
resistance.html  # 전류와 저항 페이지 구조(회로 SVG 포함)
resistance.css   # 스타일 (회로/그래프 테마)
resistance.js    # 전류 애니메이션 · R-I 반비례 그래프 계산
```

# AR 가속도 측정 (카메라 + 센서)

## 개요

폰 **카메라 영상을 배경**으로 깔고, 기기의 **가속도 센서(DeviceMotion)** 로
가속도를 측정해 화면에 겹쳐 증강현실(AR)처럼 보여 줍니다. 가속도 크기
|a| = √(aₓ²+a_y²+a_z²)를 실시간 표시하고 가속도–시간 그래프로 분석합니다.

## 기능

- **AR 시작**: 후면 카메라(`getUserMedia`) 배경 + 동작 센서 권한 요청(iOS는 1회 허용)
- **실시간 HUD**: 카메라 위에 |a| 수치와 X·Y·Z 축 막대를 오버레이
- **중력 포함/제외 토글**: 제외 시 정지 상태 ≈ 0, 포함 시 정지 상태 ≈ 9.8 m/s²
- **측정 시작/정지**: 최대 가속도와 측정 시간을 기록
- **실시간 측정값**: 가속도 |a|, 최대 |a|, 측정 시간
- **a–t 그래프**: 최근 6초간 가속도 크기 트레이스 + 최대값 표시
- **데모 신호**: 센서가 없는 기기(PC 등)에서는 합성 신호로 측정 과정을 시연

## 모형 설명

- 가속도 크기 |a| = √(aₓ² + a_y² + a_z²)

# Pico 온도 측정 (Pico 2 W + 방수 온도센서)

## 개요

다른 실험들이 브라우저 시뮬레이션인 것과 달리, 이 항목은 **실제 하드웨어**입니다.
**Raspberry Pi Pico 2 W**에 **방수 온도센서(DS18B20)** 를 연결하고 Pico 자체를
**WiFi 웹서버**로 띄워, 같은 WiFi의 스마트폰·PC 브라우저로 접속해 온도를 측정합니다.

## 기능

- **Pico가 직접 웹서버**: 인터넷·PC 프로그램 없이 `http://<Pico-IP>` 로 접속
- **▶ 시작 / ■ 정지**: 시작하면 1초마다 온도를 기록, 정지하면 멈춤
- **💾 CSV 저장**: 측정 데이터를 엑셀/구글시트에서 열 수 있는 `.csv` 파일로 다운로드
- **실시간 온도·그래프**: 큰 숫자 표시 + 온도–시간 그래프, 측정 개수/시간/최저·최고

## 파일

```
pico/
├── main.py     # WiFi 접속 + DS18B20 읽기 + HTTP 서버(논블로킹)
├── web.html    # 브라우저 제어 페이지(시작/정지/CSV 저장 + 그래프)
├── config.py   # WiFi 정보·센서 GPIO 핀·측정 간격 설정
└── README.md   # 배선도·펌웨어 설치·실행 방법 안내
```

자세한 배선과 설치 방법은 [`pico/README.md`](pico/README.md)를 참고하세요.

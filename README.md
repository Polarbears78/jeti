# 기체 법칙 가상 실험 (Gas Laws Virtual Lab)

모바일 기기에 최적화된 기체 법칙 인터랙티브 시뮬레이션 모음입니다.
두 페이지는 상단 메뉴로 서로 이동할 수 있습니다.

- **보일 법칙** (`index.html`): 온도 일정 → 압력과 부피의 반비례 관계
- **샤를 법칙** (`charles.html`): 압력 일정 → 온도와 부피의 정비례 관계

---

# 보일 법칙 (Boyle's Law)

## 개요

온도가 일정할 때 기체의 **압력(P)** 과 **부피(V)** 가 반비례한다는
보일 법칙(P₁V₁ = P₂V₂)을 손으로 직접 조작하며 관찰할 수 있습니다.

## 기능

- **피스톤 드래그**: 실린더의 피스톤을 위아래로 끌어 부피를 조절 (터치/마우스)
- **슬라이더 조작**: 손가락으로 부피를 정밀하게 조절
- **실시간 측정값**: 부피 V, 압력 P, 그리고 일정하게 유지되는 P×V 값 표시
- **압력 게이지**: 부피 변화에 따라 바늘이 실시간으로 움직임
- **기체 입자 운동 애니메이션**: 입자가 실제로 직선 운동하다 벽에 충돌·반사
- **벽 충돌 시각화**: 입자가 벽에 부딪히는 순간 섬광 효과 표시, 부피가 줄면 충돌이 잦아짐
- **충돌 빈도 측정**: 지난 1초간 벽 충돌 횟수(회/초)를 막대와 숫자로 표시 (압력과 비례)
- 온도가 일정하므로 입자의 **속력은 일정**하게 유지(등온) — 충돌 *빈도*만 변함
- **P–V 그래프**: 반비례 곡선 위에 현재 측정점을 실시간 표시
- **초기화 버튼**: 기본 상태(V=5L, P=1atm)로 복원

## 사용 방법

`index.html` 파일을 모바일 브라우저(또는 PC 브라우저)에서 열면 됩니다.
별도의 빌드나 서버가 필요 없는 순수 HTML/CSS/JavaScript 구성입니다.

```
index.html   # 페이지 구조
style.css    # 모바일 반응형 스타일
script.js    # 물리 계산 · 입자/그래프 시뮬레이션
```

## 물리 모델

- PV = K (상수), 기준점 V=5L → P=1atm 이므로 K=5
- 온도 300K로 고정 (등온 과정)
- 부피 범위: 1 L ~ 10 L

# 샤를 법칙 (Charles's Law)

## 개요

압력이 일정할 때 기체의 **부피(V)** 가 **절대온도(T, K)** 에 정비례한다는
샤를 법칙(V₁/T₁ = V₂/T₂)을, 온도와 입자 운동의 관계로 관찰할 수 있습니다.

## 기능

- **온도 슬라이더**: 가열/냉각으로 온도(100~600K) 조절 — 불꽃과 온도계가 함께 반응
- **입자 속력 ↑**: 온도가 오르면 입자가 더 빠르게 운동 (속력 막대로 표시)
- **부피 ∝ T**: 빨라진 입자가 피스톤을 밀어 올려 부피가 커짐 (압력은 일정)
- **온도별 입자 색**: 차가울 때 하늘색 → 뜨거울 때 빨강으로 변화
- **실시간 측정값**: 온도 T, 부피 V, 그리고 일정하게 유지되는 V÷T 값
- **V–T 그래프**: 원점을 지나는 정비례 직선 위에 현재 측정점 표시
- **초기화 버튼**: 기본 상태(T=300K, V=5L)로 복원

## 물리 모델

- V / T = 상수 (압력 일정), 기준점 T=300K → V=5L 이므로 상수 = 1/60
- 입자 속력은 온도가 높을수록 빠르게 (시각화는 상댓값으로 온도에 비례 표시)
- 온도 범위: 100 K ~ 600 K, 부피 범위: 약 1.7 L ~ 10 L

## 파일

```
charles.html  # 샤를 법칙 페이지 구조
charles.css   # 스타일 (따뜻한 테마 + 불꽃)
charles.js    # 물리 계산 · 입자/그래프 시뮬레이션
```

# 아보가드로 법칙 (Avogadro's Law)

## 개요

온도와 압력이 일정할 때 기체의 **부피(V)** 가 기체 **입자 수(N, 몰 수)** 에
정비례한다는 아보가드로 법칙(V₁/N₁ = V₂/N₂)을 관찰할 수 있습니다.

## 기능

- **주입 / 배출 버튼·슬라이더**: 기체 양(1~10 mol)을 늘리거나 줄임
- **입자 수 변화**: 기체를 넣으면 화면의 입자 개수가 실제로 늘어남
- **부피 ∝ N**: 입자가 많아진 만큼 피스톤이 올라가 부피가 비례해 커짐
- **밀도·속력 일정**: 입자 수와 부피가 함께 늘어 밀도가 유지되므로 압력·온도 일정
- **실시간 측정값**: 입자 수 N, 부피 V, 그리고 일정하게 유지되는 V÷N 값
- **V–N 그래프**: 원점을 지나는 정비례 직선 위에 현재 측정점 표시
- **초기화 버튼**: 기본 상태(N=5mol, V=5L)로 복원

## 물리 모델

- V / N = 상수 (온도·압력 일정), 기준점 N=5mol → V=5L 이므로 상수 = 1
- 입자 속력 일정(온도 일정), 단위 부피당 입자 수(밀도) 일정 → 압력 일정
- 기체 양 범위: 1 mol ~ 10 mol, 부피 범위: 1 L ~ 10 L

## 파일

```
avogadro.html  # 아보가드로 법칙 페이지 구조
avogadro.css   # 스타일 (초록 테마)
avogadro.js    # 물리 계산 · 입자/그래프 시뮬레이션
```
